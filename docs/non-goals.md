# Non-goals

Version 1 will not do these. They wait until after the weekend build, or they
never happen.

- Multi-user or collaborative use. One person, one install.
- Bulk photo management. Family photos stay in a photo library; only curated
  shots come here.
- Multi-node sync, or any deployment target beyond one home server.
- A REST API for its own sake. Machine interfaces exist only where an
  integration needs them (ingest, the wall, and later MCP and Telegram).
- MCP, embeddings, type proposals, Telegram, purge, a native iOS app, or
  data-defined types. Those are on the roadmap, not version 1.
- An event journal, revisions, folds, or Go modules. That was the previous
  system.

The spec lists the same non-goals under purpose and scope, plus accepted
risks (cloud model for everything; stale AI fields keep their last value).
